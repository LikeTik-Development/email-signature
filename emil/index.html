Deine neue E-Mail-Signatur

Einmal einrichten, danach steht sie automatisch unter deinen Mails.

  1. Öffne Spacemail, klick auf das Zahnrad für die Einstellungen, dann auf die Kachel „Signature“ und auf „Manage signatures“.
  2. Leg eine neue Signatur an und gib ihr einen Namen, zum Beispiel „LikeTik DE“.
  3. Klick hier unten bei „Deutsch“ auf „Signatur kopieren“. Geh zurück zu Spacemail, klick in das Textfeld und füge sie mit Cmd+V ein (Windows: Strg+V). Steht dort schon etwas, lösch es vorher.
  4. Speichern und die Signatur mit dem Häkchen als Standard festlegen. Für Englisch legst du auf dieselbe Weise eine zweite Signatur an.
  5. Schick eine kurze Testmail an Deniz, damit wir prüfen, ob alles richtig ankommt.
